# 可迭代的思考设计

目标：让玩家依据公开证据更新私人判断，比较行动的信息收益和暴露风险，并用固定场景比较版本。不能把更长的分析或小样本胜负当成进步。

局内循环：观察（引用公开记录）→ 至少两种解释 → 选择行动 → 公开表达 → 根据实际结果更新。私人记忆只保存短小的结构化决策摘要；不请求或展示完整思维链。玩家只能看到自己的词和公开记录，记忆限定在当前玩家当前对局。

保留 baseline（原版）和 evidence（证据与记忆版）。先比较训练场景，按实际失败样例实现下一版，再用未参与修订的留出场景复测。所有版本使用相同公开输入、人格、模型和评分标准。固定场景比较测量行为质量，不估计整局胜率。

规划失败时降级原版表达；规划有独立时间和输出上限，用量纳入账单。行动仍复用现有发言校验和重试。投票同一轮使用冻结快照，避免后投者看到本轮新票。

实验使用网页已有模型设置，经本地服务调用；API Key 不写报告、不打印、不写盘。固定实验预设限制调用规模，报告包括全部失败、输出、用量、延迟和盲评结果。实验入口仅在 ENABLE_GOD_VIEW=true 时开放。

验收：记忆隔离、非法引用、超时降级、用量、冻结投票的行为测试通过；实际完成至少两轮比较并保存报告；说明成本及证据局限，保留版本切换。
