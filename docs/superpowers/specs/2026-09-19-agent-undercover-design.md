# agent-undercover 设计文档

日期：2026-09-19  
仓库：https://github.com/Heliostest/agent-undercover  
状态：已与产品方对齐，待实现计划

## 1. 目标

做一个**多 agent「谁是卧底」**网页旁观游戏：四个 AI 玩家自动发言、投票，人在浏览器里看牌桌。

### v1 范围

- 纯 AI 玩家（4 人：3 平民 vs 1 卧底）
- 经典双词规则（平民同词，卧底近义异词）
- 简单网页旁观 UI
- 同一智谱 BigModel 模型 + 不同人设
- 单体全栈（方案 A）：Next.js 风格应用，逻辑模块边界清晰，便于日后拆分

### 明确延后

- 空白卧底规则
- 真人入座
- 多模型混搭 UI / 热切换
- 登录、多局持久化、战绩
- 终端或其他平台移植
- 真·多进程 agent 隔离

## 2. 规则（经典双词）

1. 开局随机指定 1 名卧底，其余为平民；从词库抽取一对近义词，平民拿到 A，卧底拿到 B。
2. **发言轮**：存活玩家按序描述自己的词（1～3 句），不得直接念出词面。
3. **投票轮**：每人必须投一名其他存活玩家；得票最高者出局。平票：再投一轮；仍平则在最高票候选人中随机出局（规则写死，避免卡死）。
4. 重复发言→投票，直到分出胜负。
5. **胜负**：
   - 卧底出局 → 平民胜
   - 场上仅剩 2 人且其中含卧底 → 卧底胜

## 3. 架构（方案 A）

单体全栈应用：服务端跑裁判与四人 LLM 轮询，前端订阅事件刷新牌桌。

### 模块

| 模块 | 职责 |
|------|------|
| `GameState` | 座位、角色、存活、轮次、公开日志；**不含**向前端默认暴露的私有词 |
| `Judge` | 发词、控阶段、收投票、判定胜负、推进循环 |
| `PlayerAgent` ×4 | 仅见自己的词 + 公开日志；输出发言或投票 |
| `LlmClient` | 智谱 BigModel HTTP 封装 |
| `WordBank` | 平民/卧底近义词对 |

### 技术栈

- Next.js（App Router）+ TypeScript
- 游戏逻辑为纯 TS 模块（`lib/`），不耦合 React 组件
- 智谱：chat completions 形态；环境变量 `ZHIPU_API_KEY`、`ZHIPU_MODEL`
- 实时：每局 `gameId`，服务端 SSE 推送事件
- 词库：内置 `data/word-pairs.json`

### 数据流

1. 浏览器 `POST /api/games` → 创建并启动一局
2. Judge 循环：选行动者 → `PlayerAgent.act(state)` → 写入公开日志 → SSE 推送
3. 浏览器只渲染公开视图；可选「上帝视角」查看私有词与身份（默认关闭）

### SSE 事件（v1）

- `phase`：阶段变化（setup / speak / vote / result / error）
- `speech`：某座位发言
- `vote`：某座位投票及理由
- `result`：出局、胜负
- `error`：不可恢复错误（含硬超时）

## 4. UI

- 顶栏：局号、阶段、开始 / 再来一局
- 四人座位卡：名字、人设短标签、存活/出局、是否正在行动
- 中间：发言时间线
- 底部：投票条（谁投谁 + 本轮汇总）
- 调试：上帝视角开关（默认关）

## 5. Agent 行为

- 同模型，四套 system 人设示例：谨慎分析 / 幽默带节奏 / 激进带节奏 / 少话观察
- 发言：结合私有词与公开日志；禁止念出词面
- 投票：必须投存活他人，附一句短理由（理由进入公开日志）
- 输出优先结构化（内部 JSON → 再渲染上屏），温度偏低以减少胡话

## 6. 容错

- 智谱超时 / 429：指数退避，最多 2 次
- Agent 输出不合格：重试 1 次 → 仍失败则兜底（标记空发言，或随机合法票），日志标红
- 单局硬超时：结束并推 `error`
- 缺 API Key：创建局时直接返回可读错误，不空跑

## 7. 测试（v1）

- 纯函数：胜负判定、平票规则、发词不泄露到公开状态
- Judge + mock LLM：整局能正常结束
- 暂不做浏览器 E2E

## 8. 仓库结构

```
app/                      # 页面与 API routes
lib/game/                 # GameState, Judge, phases
lib/agents/               # PlayerAgent, personas
lib/llm/                  # Zhipu client
data/word-pairs.json
docs/superpowers/specs/   # 本设计文档
```

## 9. 成功标准（v1）

- 本地配置智谱 Key 后，一点「开始」能自动跑完一局并在网页看到发言、投票、胜负
- 默认视图不泄露卧底身份与私有词；上帝视角可调试
- 无 Key / 模型失败时有明确提示，不出现无限挂起
